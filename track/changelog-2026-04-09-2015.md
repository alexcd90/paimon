## 本次进展亮点

### 1. PyPaimon SQL 查询能力正式上线

本次最重要的更新是为 PyPaimon 引入了基于 **DataFusion** 的 SQL 查询引擎：

```python
from pypaimon.sql import SQLContext

ctx = SQLContext({'warehouse': '/path/to/warehouse'})
result = ctx.execute("SELECT * FROM default.my_table WHERE dt = '2024-01-01'")
print(result.to_pandas())
```

同时提供 CLI 命令行接口：
```bash
pypaimon sql --warehouse /path/to/warehouse "SELECT count(*) FROM default.my_table"
```

### 2. PyPaimon Lumina 向量索引搜索

PyPaimon 现已支持向量相似性搜索（ANN），可直接调用 Lumina 向量索引：

```python
builder = table.new_vector_search_builder()
builder.with_vector_column('embedding')
builder.with_query_vector([0.1, 0.2, 0.3, 0.4])
builder.with_limit(5)
result = builder.execute_local()

read_builder = table.new_read_builder()
scan = read_builder.new_scan().with_global_index_result(result)
arrow_table = read_builder.new_read().to_arrow(scan.plan().splits())
```
