## 详细说明

### 关于 BucketsTable 谓词下推功能

本次更新为系统表 `BucketsTable` 引入了谓词下推能力，主要改进包括：

1. **分区过滤支持**：可以通过 `partition` 字段进行等值或 IN 条件过滤
2. **桶过滤支持**：可以通过 `bucket` 字段进行等值过滤
3. **组合过滤**：支持 partition 和 bucket 的联合过滤条件

**使用示例**：
```sql
-- 查询特定分区的桶信息
SELECT * FROM my_table$buckets WHERE partition = '{2024-01-01}';

-- 查询特定桶
SELECT * FROM my_table$buckets WHERE bucket = 0;

-- 组合条件
SELECT * FROM my_table$buckets WHERE partition = '{2024-01-01}' AND bucket = 0;
```

### 代码重构亮点

- 提取了 `PartitionPredicateHelper` 工具类，将分区谓词处理逻辑从 `FilesTable` 和 `FileKeyRangesTable` 中抽离，实现代码复用
- 统一的分区规范解析方法 `parsePartitionSpec`，支持标准分区字符串格式
