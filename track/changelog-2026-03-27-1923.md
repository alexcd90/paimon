### 1. Fix | spark | Fix nested struct field mapping for V2 write merge schema

- **commit**：`9d7c54ff1`（作者：Zouxxyy，时间：2026-03-27）
- **类型**：Fix
- **摘要**：修复 Spark V2 写入合并 Schema 时嵌套 Struct 字段映射错误的问题。当数据 Schema 与表 Schema 字段顺序不一致时，嵌套 Struct 的字段位置计算错误，导致读取到错误数据或空值。核心修改包括：在 `SparkInternalRowWrapper` 中保存 `dataSchema` 引用，修复 `getBlob` 方法使用实际字段位置，以及递归处理嵌套 Struct 的字段映射。
- **关键文件**：

  - [`V2WriteMergeSchemaTest.scala`](file:///e:/project/java-project/paimon/paimon-spark/paimon-spark-ut/src/test/scala/org/apache/paimon/spark/sql/V2WriteMergeSchemaTest.scala)：新增 5 个测试用例覆盖嵌套 Struct 新增字段、深层嵌套、缺失字段、类型演化等场景

### 2. Feature | flink | Support refreshing partition asynchronously for lookup join

- **commit**：`b9631eeb5`（作者：umi，时间：2026-03-27）
- **类型**：Feature
- **摘要**：为 Flink Lookup Join 新增异步分区刷新功能。新增配置项 `lookup.dynamic-partition.refresh.async`，启用后分区变更将在后台线程中加载，旧分区数据在刷新期间继续提供查询服务，避免同步刷新阻塞查询。核心实现为新增 `PartitionRefresher` 类，通过 `ScheduledExecutorService` 定期异步检测并加载新分区数据。
- **关键文件**：
  - [`PartitionRefresher.java`](file:///e:/project/java-project/paimon/paimon-flink/paimon-flink-common/src/main/java/org/apache/paimon/flink/lookup/PartitionRefresher.java)：新增异步分区刷新器，负责后台线程定期检测分区变更并异步加载
  - [`FileStoreLookupFunction.java`](file:///e:/project/java-project/paimon/paimon-flink/paimon-flink-common/src/main/java/org/apache/paimon/flink/lookup/FileStoreLookupFunction.java)：集成 `PartitionRefresher`，在异步模式下委托刷新逻辑
  - [`FullCacheLookupTable.java`](file:///e:/project/java-project/paimon/paimon-flink/paimon-flink-common/src/main/java/org/apache/paimon/flink/lookup/FullCacheLookupTable.java)：新增 `refreshAsync` 方法支持异步表刷新
