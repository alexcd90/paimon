### 1. Perf | core | Extract Parquet stats from in-memory footer instead of re-reading file

- **commit**：`bec54fdd4`（作者：majian，时间：2026-04-02 11:12 +0800）
- **类型**：Perf / Fix
- **摘要**：当前 Paimon 在写入 Parquet 文件关闭后会重新读取文件 footer 以提取列统计信息，在 OSS 等对象存储上因最终一致性可能引发 `FileNotFoundException`。本次变更将 `ParquetMetadata` 在 writer close 时缓存到内存（通过 `ParquetWriter.getFooter()`），并将其传递给统计信息提取流水线，避免重新读文件；非 Parquet 格式则回退到原有的文件读取路径。

### 2. Fix | api | Fix locale-sensitive date formatting in DLFOpenApiSigner

### 8. Fix | spark | Fix view query failure with VARCHAR/CHAR column types

- **commit**：`409dd85e5`（作者：Zouxxyy，时间：2026-04-02 21:52 +0800）
- **类型**：Fix
- **摘要**：查询含 VARCHAR/CHAR 列的 Paimon View 时报错 "Cannot up cast from STRING to VARCHAR(n)"。原因是 Spark 在 V2 表解析时将 `CharType`/`VarcharType` 替换为 `StringType`，但视图 schema 仍保留原始类型，导致 `UpCast(StringType → VarcharType)` 失败。修复方案是在 `PaimonViewResolver` 中使用 `CharVarcharUtils.replaceCharVarcharWithStringInSchema` 对视图 schema 进行归一化，再执行 UpCast。
- **关键文件**：
  - [`paimon-spark/paimon-spark-common/src/main/scala/org/apache/paimon/spark/catalyst/analysis/PaimonViewResolver.scala`](file:///e:/project/java-project/paimon/paimon-spark/paimon-spark-common/src/main/scala/org/apache/paimon/spark/catalyst/analysis/PaimonViewResolver.scala)：在构建 alias 前调用 `replaceCharVarcharWithStringInSchema` 归一化视图 schema
  - [`paimon-spark/paimon-spark-ut/src/test/scala/org/apache/paimon/spark/sql/PaimonViewTestBase.scala`](file:///e:/project/java-project/paimon/paimon-spark/paimon-spark-ut/src/test/scala/org/apache/paimon/spark/sql/PaimonViewTestBase.scala)：新增 VARCHAR 和嵌套 VARCHAR/CHAR 场景的视图查询测试

### 9. Fix | core | Fix partial-update sequence-group delete mismatch under projected reads

- **commit**：`4a4907d6b`（作者：bryndenZh，时间：2026-04-02 22:58 +0800）
- **类型**：Fix
- **摘要**：在 partial-update 表的投影读场景下，`sequenceGroupPartialDelete` 中存储的是原始表的字段索引，而投影后列的索引重新映射，导致 sequence-group 触发删除时索引不匹配。修复方案是在创建投影后的 merge function 实例时，同样对 `sequenceGroupPartialDelete` 中的索引做映射转换（过滤掉不在投影列中的字段，并将剩余索引重映射到新位置），确保投影读下的删除语义正确。
- **关键文件**：
  - [`paimon-core/src/main/java/org/apache/paimon/mergetree/compact/PartialUpdateMergeFunction.java`](file:///e:/project/java-project/paimon/paimon-core/src/main/java/org/apache/paimon/mergetree/compact/PartialUpdateMergeFunction.java)：新增 `projectedSequenceGroupPartialDelete` 变量并在投影时对其做索引重映射
