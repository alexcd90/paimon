## 本次进展亮点

### 1. Lumina 向量索引支持 Flink 增量构建

Lumina 向量索引现在支持在 Flink 中进行**增量构建**，无需每次全量重建索引，显著降低资源消耗，适合持续写入的实时向量检索场景。

### 2. FileType 枚举统一文件分类

新增 `FileType` 枚举，将 Paimon 内部各类文件（数据文件、Manifest、Schema、Snapshot、Tag、Consumer 等）统一建模，取代散落各处的字符串常量，是一次重要的代码架构清理。

### 3. Blob 表 Schema Evolution 修复

修复了 Blob 表在 ALTER TABLE + Compaction 后读取失败的关键 Bug，并禁止对 blob 列执行 rename 操作，保证 Blob 数据读取稳定性。Java 和 Python 双端同步修复。

### 4. Spark SHOW TABLE EXTENDED 增强

`SHOW TABLE EXTENDED PARTITION` 命令现在支持返回分区级别的统计信息（行数、文件大小等），便于 Spark 用户快速评估分区数据规模。

### 5. Flink StreamExecutionEnvironment 兼容性

通过新增 `StreamExecutionEnvironmentUtils` 工具类，抽象 Flink 1.x 和 2.x 的环境差异，解决全局索引构建任务在不同 Flink 版本下的兼容问题。
